# 导览 App 回充环境适用说明

> **版本**：V1.0  
> **适用产品**：导览 App  
> **适用机型**：T1  
> **适用对象**：部署、运营和现场使用人员

## 先记住

回充分为两个阶段：机器人先沿已设置的地图前往充电桩前，再由前置相机识别充电桩标记并完成近距离对接。只有检测到实际充电，才算回充成功。

因此，能否稳定回充主要取决于充电桩附近的三件事：**光照、障碍物、地面**。不能只按“导览、巡检、导购或药房”判断是否支持；同一行业在不同现场的结果可能不同。

## 推荐使用环境

以下组合是当前最适合部署、也最应该优先测试的基础环境：

- **光照稳定**：充电桩标记清楚可见；避免窗边直射、强逆光、灯光频闪和完全黑暗。必要时为充电桩增加稳定的现场照明。
- **桩前畅通**：机器人前往充电桩的路线保持畅通；充电桩前方约 1 米范围内不放置箱子、推车、清洁工具或其他物品。
- **地面平整**：使用干燥、坚实、连续的硬质地面；充电桩固定牢靠，不在门槛、坡面、台阶或容易打滑的位置。
- **标记和位置稳定**：充电桩视觉标记保持清洁、无遮挡；充电桩移动或改变朝向后，先重新设置回充位置。

## 首批重点测试场景

这里的“高频”指各行业中最常见、且符合上述基础环境的运行组合，不代表已经完成现场频次统计。首批测试应优先覆盖这些组合，再验证现场的变化条件。

| 典型场景 | 可优先保障的环境组合 | 重点测试的变化 |
| --- | --- | --- |
| 展厅导览 | 固定室内展厅、照明稳定、平整硬地面；充电桩位于非主通道，桩前可保持空置 | 观众经过导航路线、展柜或玻璃附近的光线变化；桩前不能被观众或展品堵住 |
| 物业巡检 | 办公楼或园区室内固定通道；夜间仍有稳定照明；地面平整干燥 | 夜间照明、临时保洁车和物料；门槛、坡道和狭窄通道应在现场验证前排除 |
| 商场导购 | 室内固定路线、正常照明、平整硬地面；充电桩放在不受持续人流干扰的位置 | 营业高峰的人流和推车；可以测试路线上的动态障碍，但对接时桩前必须清空 |
| 智慧药房 | 药房后场或固定室内通道；照明连续、地面平整；充电桩附近无推车和货物堆放 | 夜间或后场的照明变化、货箱和周转车；玻璃、金属和高反光地面需单独验证 |

**建议的测试基线**：先在“固定室内 + 稳定照明 + 平整干燥硬地面 + 桩前畅通”的组合下验证多次回充，再逐项加入人流、临时物品和光线变化。不要把所有变化条件一次叠加，否则难以判断失败原因。

## 可以使用，但要先现场验证

以下情况不应直接视为稳定支持，适合在真实部署地点进行验证，并通过调整环境降低风险：

- 白天和夜间亮度不同，但可以为充电桩保持连续、稳定的照明。
- 导航路线偶尔有人或普通物体经过，但回充时可以保证机器人前方和桩前区域畅通。
- 普通地砖、木地板或轻微反光地面，机器人行驶不打滑，且相机仍能清楚看到充电桩标记。
- 充电桩靠近玻璃展柜、金属设施或店面灯光，但可以通过改变朝向或位置避免直射和强反光。

现场验证时，应同时观察“能否到达桩前”和“能否识别标记并建立充电”。只到达桩前，不代表已经完成回充。

## 不建议直接依赖自动回充

| 现场情况 | 主要风险 | 简单处理方式 |
| --- | --- | --- |
| 强逆光、完全黑暗、灯光频闪或强反光直射相机 | 充电桩标记可能无法稳定识别 | 增加稳定照明、调整充电桩朝向或更换点位；仍无法改善时采用人工回充 |
| 视觉标记被遮挡、污损、损坏，或充电桩已移动 | 相机识别结果与已设置位置不一致 | 清理并露出标记；固定充电桩；移动或改向后重新设置回充位置 |
| 桩前持续有人流、推车、箱子或清洁工具，无法保持约 1 米空置 | 激光雷达发现障碍后会停止，近距离对接也不安全 | 设置空置区、调整充电桩位置或安排空闲时段回充；无法清空时人工处理 |
| 细小、透明、低矮或悬空障碍物较多 | 简单激光雷达避障不能保证稳定发现 | 清理或隔离这些障碍物；不要依赖机器人自动穿过该区域 |
| 积水、湿滑、镜面或强反光地面，厚地毯、松动地垫、门槛、坡面、台阶或凹凸地面 | 可能造成打滑、姿态偏差或视觉干扰 | 将充电桩移到平整、干燥、坚实的地面；无法调整时采用人工回充 |
| 充电桩前方或通往充电桩的路线长期狭窄，必须穿过复杂人流或无法绕开的门槛 | 导航和近距离对接都缺少稳定余量 | 更换充电桩点位，或由现场人员把机器人移至充电桩处充电 |

## 上线前检查

部署或更换场地后，按下面顺序检查：

- [ ] 充电桩已经固定，视觉标记清洁、完整且没有被设备或装饰遮挡。
- [ ] 相机看向充电桩时没有强逆光、频闪或强反光；夜间照明不会被关闭。
- [ ] 从任务区域到充电桩的导航路线畅通，没有无法稳定识别的细小、透明、低矮或悬空障碍物。
- [ ] 充电桩前方约 1 米没有人员停留、推车、箱子或其他物品。
- [ ] 充电桩所在位置平整、干燥、坚实，没有门槛、坡面、台阶、地垫或明显打滑风险。
- [ ] 充电桩位置或朝向发生变化后，已经重新设置回充位置。
- [ ] 在实际工作时段完成回充验证，并确认设备进入“充电中”，而不是只到达充电桩前。

## 回充失败时怎么处理

1. 先看回充状态提示，确认是路线受阻、视觉标记不可见、充电桩位置变化，还是没有建立充电。
2. 清理桩前区域，检查照明、视觉标记和地面，再按提示重试。
3. 如果同一环境反复失败，或现场条件无法调整，不要连续重复自动回充；保持现场安全，由人员人工处理或把充电桩移到推荐环境后重新设置。

回充没有建立实际充电时，不要把“已经到达充电桩”当作“充电成功”。充电桩位置变化、地面变化或现场照明变化后，应重新做一次现场验证。

## 一句话判断

**看得清、路上没有难发现的障碍、地面平且不滑、桩前能空出约 1 米，适合优先测试自动回充；其中任一条件长期无法满足，就应调整现场或改用人工回充。**
