# 回充状态机图

本图只保留影响用户操作和任务流转的状态。具体导航、识别、对接和充电阶段属于回充执行子状态，不在页面中逐项展开。

```mermaid
stateDiagram-v2
    direction LR

    [*] --> Idle: 任务空闲 / 返回初始点
    Idle --> OneClickReady: 已有有效地图和回充位置
    Idle --> SetupRequired: 未选地图或未设置回充位置
    SetupRequired --> SetupRequired: 点击一键回充 / 设置回充位置
    SetupRequired --> OneClickReady: 完成回充位置设置

    OneClickReady --> OneClickPending: 用户长按一键回充
    OneClickPending --> Returning: 前置检查通过
    OneClickPending --> SetupRequired: 地图或回充位置无效
    OneClickPending --> WaitingControl: 遥控器 / SDK / 其他 App 占用控制权
    OneClickPending --> SafeStopped: 姿态、定位或设备状态不满足

    Returning --> Charging: 成功到达充电桩并建立充电
    Returning --> RecoveryConfirm: 导航、识别或对接异常
    Returning --> WaitingControl: 外部控制接管
    Returning --> SafeStopped: 用户停止回充

    Charging --> ChargingInterrupted: 充电中断或充电状态丢失
    Charging --> ChargeComplete: 达到充电完成条件
    Charging --> WaitingControl: 外部控制接管
    Charging --> SafeStopped: 用户停止回充

    ChargingInterrupted --> RecoveryConfirm: 显示异常，等待用户决定
    RecoveryConfirm --> Returning: 用户确认重试 / 恢复回充
    RecoveryConfirm --> SafeStopped: 用户退出回充或未确认

    ChargeComplete --> Idle: 一键回充完成，保持在桩上
    ChargeComplete --> ResumePlan: 自动回充且存在有效恢复安排
    ResumePlan --> ResumePoint: 到达用户配置的恢复时间
    ResumePoint --> TaskRunning: 前往恢复点并启动任务首步骤
    TaskRunning --> Idle: 任务完成

    WaitingControl --> ControlReleased: 外部控制权释放
    ControlReleased --> RecoveryConfirm: 弹出恢复确认，不自动恢复
    ControlReleased --> SafeStopped: 用户未确认 / 保持安全停止

    SafeStopped --> RecoveryConfirm: 用户重新发起或打开待确认操作
    SafeStopped --> Idle: 用户退出本次回充
```

## 回充执行子状态

```mermaid
stateDiagram-v2
    direction LR
    [*] --> NavigateToDock: 前置检查通过
    NavigateToDock --> DetectDock: 到达桩前区域
    DetectDock --> Docking: 识别充电桩
    Docking --> ChargingEstablished: 对接成功
    ChargingEstablished --> [*]: 建立充电

    NavigateToDock --> SingleFailure: 首次导航异常
    DetectDock --> SingleFailure: 首次识别异常
    Docking --> SingleFailure: 首次对接异常
    SingleFailure --> NavigateToDock: 用户确认重试
    SingleFailure --> RepeatedFailure: 再次失败
    RepeatedFailure --> [*]: 停止回充，等待人工处理
```

## 关键转移约束

- 一键回充完成后保持在充电桩，不自动恢复导览任务。
- 自动回充完成后，只有存在有效恢复安排时才离桩；没有恢复安排时回到任务起点并启动首步骤。
- 低电提醒由用户确认是否在当前讲解完成后回充；紧急缺电直接停止当前任务进入回充，但恢复或退出仍由用户确认。
- 遥控器、SDK 或其他 App 接管时不抢占控制权。控制权释放后只弹出确认，不由机器人自行恢复。
- 新任务可以清除旧任务的恢复安排，但保留“是否恢复自动回充”的待确认操作。
